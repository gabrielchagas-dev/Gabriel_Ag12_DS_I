## Como abrir
Extraia todos os arquivos do ZIP e abra index.html no navegador.
As cinco imagens ficam na mesma pasta do HTML e abrem sem internet.
Para acessar os sites pelos links, é necessário estar conectado.

## Conteúdo
- index.html: página com comentários no código e estilos internos.
- Cinco imagens PNG dos sites escolhidos.
- capturas: execução no navegador e visualização do código comentado.
