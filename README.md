# Meus sites favoritos

Aluno: Gabriel das Chagas Silva.
Atividade da Agenda 12 de Desenvolvimento de Sistemas I.

## Sobre a página
Página pessoal com YouTube, GitHub, LinkedIn, Outlook e Teams.
O tema escuro, azul e roxo e os cinco sites foram escolhidos pelo aluno.
O texto menciona o estágio na CM Capital conforme informação fornecida
pelo aluno. Esta é uma atividade escolar pessoal.

## Como abrir
Extraia o ZIP inteiro e abra index.html no navegador.
Mantenha os cinco arquivos PNG na mesma pasta do HTML.
As imagens abrem sem internet. Os links precisam de conexão;
Outlook e Teams podem solicitar login na conta do usuário.

## Arquivos
- index.html: página HTML com CSS interno e comentários.
- youtube.png, github.png, linkedin.png, outlook.png, teams.png: imagens locais.
- capturas: código comentado e execução no navegador.

## Créditos
Ícones dos sites, obtidos pelo serviço público Google S2 Favicons.
Marcas pertencem aos respectivos titulares.
Página desenvolvida com auxílio de IA e personalizada com as escolhas do aluno.
